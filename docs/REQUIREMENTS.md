## 2. 画面レイアウト（縦）

- 使用可能エリア = 画面全体から上部パンチホール・ノッチを除いた領域
- 中央に当月カレンダーを大きく表示
- その上下に先月・来月を同サイズで縮小表示（当月末〜使用可能エリア端に収める）
- **個々のカレンダー（1ヶ月ブロック）の縦横比は 1:1（正方形）**。ヘッダ＋曜日＋6行グリッドを正方形枠に収める（参考: `docs/reference/8月.png` / `9月.png`）
- 全体レイアウト: 使用可能エリア中央に当月の正方形をできるだけ大きく（幅・高さの小さい方にフィット）。残った上下（横画面では左右）余白から前後月の正方形スケールを決定（uniform・潰れ禁止）
- 使用可能エリアが正方形に近い場合は **4:3** として扱う（画面レターボックス用。月ブロック自体は常に1:1）。縦: 高さ/幅を `[4/3, 21/9]` にクランプ
- **縦/横ストリップの分岐**: usable W/H で判定（`Configuration.orientation` 禁止）。**H≥W → 縦**（1:1含む・上下に前後月）、**W>H → 横**（左右に前後月）
- あまりにも縦長の場合は **21:9** として扱う（同上）
- 左上余白: 時刻・バッテリー残量・通信状態（Wi-Fi or モバイル強度）。余白が狭いときは縮小
- 背景は参考画像どおり黒想定（要確認）
- 日曜・祝日は赤、土曜は青（色味は見やすさで調整可）
- 当日表示: **その日のグリッドマス全体**を角丸枠で囲む（数字の周囲だけではない）
- 日付数字: 各日セル短辺の目安 **90%** 程度。その月の全日付で同一フォントサイズ（`"00"` 相当で測り、1桁/2桁でスケールを変えない）
- 週の並びは参考画像どおり **日曜始まり**（日〜土）
- 月ヘッダ参考: `2026` / `9` / `September`（英月名併記）

## 3. 画面レイアウト（横）

- パンチホール・ノッチを避けつつ、左:先月（小）・中央:当月（大）・右:来月（小）※原文「右:先月」は来月の誤記と解釈（要確認）
- **中央正方形を高さ最大**（side = 使用可能エリア高さ。幅不足時のみ幅で制限）→ その後、左右余白から前後月の正方形スケール（縦の上下余白と同じ手順の左右版）。中央を先に小さくしない
- **アスペクト補正（縦と対称）**: 使用可能エリアの幅/高さを `[4/3, 21/9]` にクランプして画面レターボックス
  - 正方形寄り（幅:高さ < 4:3）→ **4:3** として扱う（上下にレターボックス／高さを絞る）
  - 極端に横長（幅:高さ > 21:9）→ **21:9** として扱う（左右にレターボックス／幅を絞る）
  - 実装: `designAspectWidthOverHeight` → 有効レイアウト矩形に対して中央高さ最大→左右余白でサイド。月ブロックは常に 1:1
- **Insets**: 全画面ON → `displayCutout` のみ。全画面OFF → `systemBars` + `displayCutout`（status/nav を使用可能エリアから除外しカレンダー再レイアウト）
- **全画面表示**（デフォルトOFF）: OFF=常時 status+nav 表示・左上 StatusCluster 非表示。ON=immersive（transient swipe）＋暗幕
- **暗幕**: 全画面ONかつステータスバー表示中のみ。不透明度 **85%固定**。検知は017系（compose/compat/transient anim/端スワイプ）。debug不透明度/常時表示/ぼかしUI・キーは削除（移行時読み捨て）
- 左上ステータスは通常タテ積み（時刻／電池／電波）。**横置き（usable W>H）かつ全画面ONで StatusCluster 表示時は常に1行**（例: `15:31  76%  [wifi]`）。はみ出し予測による分岐はしない

## 4. 月切り替え操作

- 上下の小さいカレンダーをタップ → その月が中央にズームアップ。前後月が上下に再配置
- タップ確定はダブルタップタイムアウト（`ViewConfiguration` / Compose 約300ms）待ち。2回目が来たら設定（UnlockSlider）、来なければ単タップの月ジャンプ。ドラッグによる月スクロールは即時
- 上下スワイプでも月切り替え
- モーション例（前月へ）: 前月がズームアップしつつ上から中央へ / 中央月がズームアウトしつつ下へ / 下の月は画面外下へスライドアウト
- **誤操作抑止モード** ON時は月切り替え不可（ダブルタップ→設定は有効のまま）。デフォルトOFF
- 使用可能エリア全体でダブルタップ→設定（空白・前後月・今月ボタンを含む）

## 4b. 「今月」ボタン（0.0.2）

- カレンダー左下余白。`RoundedCornerShape` の角丸四角形＋枠（円形 Shape / `CircleShape` / percent=50 のピル形は使わない）。タップで当月へ（隣接月は既存±1アニメ、それ以外はスナップ）。単タップもダブルタップタイムアウト待ち（2回目→設定）
- 誤操作抑止中は非表示
- 縦（usable 縦≥横）: テキスト `今\n月`、contentPadding は横画面 Outlined 相当の視覚密度（例: 縦向き `10.dp×8.dp`。横の 14×10 を単純に軸入替しない）。`defaultMinSize` で余計な高さを付けない。正方形でも極端な縦長でもない／横: `今月`（`14.dp×10.dp`。縦書き専用部品は使わない）

## 4c. 日付色（0.0.2）

優先: **カスタム平日(白) ＞ カスタム休日(赤) ＞ 白表示スイッチ ＞ 既定**（祝日・日曜赤、土曜青、他白）

カスタム休日／平日の種別ラベル: 1日のみ / **期間指定** / 毎年 M 月 D 日 / 毎年 M 月第 N W 曜日 / 毎年 M 月末 / 毎月 D 日 / 毎月第 N W 曜日 / 毎月末 / 毎週 W 曜日（M/D/N/W の記号用スペースは選択肢ラベルのみ）。「第N曜日」は単一（範囲なし）。一覧・プレビューは具体値・値前後スペースなし（例: `毎年8月11日` / `毎年8月第2火曜日` / `毎週火曜日` / `2026/12/29～2027/01/03`）。日付は OutlinedButton→DatePicker、期間は開始・終了の縦2ボタン、M/N/W は ExposedDropdownMenu。期間は開始〜終了 inclusive、終了<開始なら保存時に入替。JSON kind=`DATE_RANGE`、start=`year/month/day`、end=`endYear/endMonth/endDay`。

## 4d. カスタム休日/平日のエクスポート・インポート（0.0.3）

- 設定: カスタム休日・カスタム平日セクション直下に「エクスポート」「インポート」
- エクスポート: Pretty JSON（`format`/`formatVersion`/`holidays`/`weekdays`）。共有 Intent（text/plain）＋クリップボード。Keep等へ貼付しやすいテキスト
- インポート: テキスト貼付。受理 (1) 包み形式 (2) 規則配列のみ→休日/平日をUI指定。`id`省略→新規UUID。未知フィールド無視。不正件はスキップし件数報告。**追加 / 全置換を必須選択**。追加時は既存と同パターン（kind＋意味フィールド、id除外）なら追加せず重複件数。全置換は従来どおり。包みに `holidays`/`weekdays` キーがあれば各カテゴリを選んだモードで適用。全置換は当該カテゴリのみ（他方は消さない）
- 手書きガイド: [`CUSTOM_DAYS_IMPORT.md`](CUSTOM_DAYS_IMPORT.md)

## 7. 日本の祝日

- データ元: https://holidays-jp.github.io/api/v1/date.json および年別 `.../api/v1/{year}/date.json`
- ライセンス: MIT（matsuoshi / monaural.net）→ 設定最下部に表記
- 取得タイミング:
  - 初回起動: 前年・今年・翌年
  - 年が変わって初起動: 前年・今年・翌年
  - 保持データのない月までスクロールしたとき
- キャッシュして取得頻度を抑える
- 取得不可（範囲外・オフライン・API障害）: トースト「祝日データが取得できません」

## 10. 充電時計開発Botからの正本（1.0.4 / aca043b）— 2026-09-27

卓常カレンダーは下記をそのまま揃える（要件の【充電時計と同一仕様】）。

- 輝度: idle_brightness 0.10f / clamp 0.01..0.35 / タップ5秒 NONE / onPause復元 / 1秒周期でidle再適用
- スリープ: allow_auto_sleep=false → KEEP_SCREEN_ON
- OLED: 180_000ms、Random -12..+12、OledShiftGuard 16.dp
- フルスクリーン: windowFullscreen + edge-to-edge + hide systemBars（TRANSIENT_BARS_BY_SWIPE）
- Discord: 1.0.4 の percent-only ThresholdFireTracker をコピー推奨（プラグ連動の旧ロジック禁止）
- 設定導線: ダブルタップ→UnlockSlider 85%/8秒 → Settings。ヒントは Settings 表示時のみ消滅。60秒5タップで再表示5秒
- landscape OFF/RIGHT/LEFT、exit_on_unplug falling edge only・default false
- フッター: OSSクレジット→バージョン。本アプリは rev ではなく debug 表記（要件どおり）
- DataStore 名・Preferenceキーは別アプリなので互換不要。必要なら別名可
- package/applicationId・表示文字列・Discord文言のアプリ名は差し替え


## 11. ユーザー確定（2026-09-27）

- 横: 左=先月 / 中央=当月 / 右=来月
- 輝度タップ復元: **60秒**（充電時計5秒と意図的に異なる）
- 迷いタップヒント: 充電時計と同じ（60秒5タップ→5秒表示）
- アスペクト（縦・横とも）: 4:3より正方形寄り→4:3、21:9より縦長／横長→21:9（画面レターボックス）。縦は高さ/幅、横は幅/高さを `[4/3, 21/9]` にクランプ。**個々の月ブロックは常に 1:1**
- 使用可能エリアがちょうど正方形（H≥W）のとき: **縦レイアウト**（上下に前後月）。判定は usable W/H（Configuration.orientation 禁止）
- applicationId `com.kmmm_engineering.alwayscalendar` / GitHub `suhamaHZK/AlwaysCalendar`
- minSdk 29 / targetSdk 36
- 時刻: 秒なし・24時間固定
- 色: 既定は黒背景＋白／赤／青。0.0.2で白表示スイッチ＋カスタム休日／平日を追加
- 月ヘッダ: 年+月数字+英語月名 / 曜日: 日〜土
- **週始まり: 日曜／月曜を設定で選択**（本アプリ固有）
- **充電中はバッテリー%の左に雷アイコン**（充電時計と同じ）
